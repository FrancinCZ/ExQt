# ExQt: Expansion microscopy QuanTification analysis of Nuclear Condensates

ExQt is an open-source, PySide6-based desktop application designed for the flexible analysis of 3D/2D biological image data, specifically optimized for Expansion Microscopy (ExM). It bridges the gap between raw imaging data, probability maps (e.g., from Ilastik), and interactive visualization using `napari`.

## Features
*   **Interactive 3D/2D Visualization:** Integration with `napari` for visual inspection of raw data, probability maps, and segmented condensates.
*   **Segmentation:** Employs customizable probability thresholds and minimum voxel constraints to strictly filter out sub-resolution noise and artifacts.
*   **Batch Processing:** Automated pipeline for processing multiple `.tif` files, outputting comprehensive spatial coordinates (Z, Y, X), biological volumes, and signal intensities.
*   **Auditability & Reproducibility:** Automatically generates statistics and graphs with metadata logs (JSON) for every batch, detailing all applied parameters (expansion factor, pixel size, thresholds).

## Installation

Installing ExQt is recommended inside an isolated virtual environment using [Conda](https://docs.conda.io/en/latest/miniconda.html) (or Mamba) to prevent dependency conflicts with other Python packages on your system.

### 1. Clone the repository
First, download the source code to your local machine:

```Bash
git clone https://github.com/FrancinCZ/ExQt.git
cd ExQt
```
### 2. Create a Conda environment

Create a new virtual environment named exqt-env with Python 3.10 (or your preferred compatible version) and activate it:

```Bash
conda create -n exqt-env python=3.10 -y
conda activate exqt-env
```

### 3. Install dependencies
Install the required packages. Ensure your activated environment is running, then install the dependencies via pip:

```Bash
pip install -r requirements.txt
```
(Note: If you encounter issues with napari or PySide6 on specific operating systems, refer to their official documentation for OS-specific binaries).

### 4. Run the application

Once everything is installed, you can launch the graphical user interface by running:

```Bash
python App.py
```

## Quick Start

To help you get familiar with ExQt, a sample dataset is provided in the `example_data/` directory.

1. **Launch the app:** Run `python App.py`.
2. **Choose the folder:** Click **Browse** and select the `example_data` directory. ExQt expects each raw image `sample.tif` to have a matching probability map named `sample_Probabilities.h5` in the same folder (this is the default export naming used by Ilastik).
3. **Set Parameters:** Select a **Process mode** (`3d`, `2d`, or `single_slice` - see [Configuration Parameters](#configuration-parameters) below) and adjust the settings (e.g., Expansion Factor, Z-step, Pixel size) according to the metadata provided in the example folder.
4. **Run Analysis:** Click **Start analysis** to begin processing the data.
5. **Review:** If you enable the **"Pause and review segmentations"** option, ExQt will pause after each image to let you visually inspect the intermediate steps in `napari` before continuing. Otherwise, the segmentation and analysis will proceed automatically in the background.
6. **Output:** The final results generated by ExQt depend on your selected preferences. Typically, the software outputs a CSV file containing the spatial coordinates (Z, Y, X) and morphological data of the detected condensates. A JSON file is also created alongside it, storing the metadata and analysis parameters used for that run, to ensure full reproducibility. If you enabled the generation of statistics and graphs, these visual summaries will be saved directly to your selected output directory.

## Configuration Parameters

### Main Settings
The main interface of ExQt provides parameters required to correctly process and scale your data.

*   **Input / Output Directories:** Define the source folder containing your raw `.tif` images and corresponding `.h5` probability maps (both must be in the same directory, see naming convention above). Select the destination folder for the results, or simply check **Save to the same folder as input**.
*   **Process mode:** ExQt is able to handle full 3D volumes (`3d`), 2D images via Maximum Intensity Projection (`2d`), or single-slice extraction (`single_slice`). In `single_slice` mode, ExQt automatically selects the sharpest Z-slice for each image using a focus-quality metric (variance of the Laplacian), rather than always projecting the whole stack.
*   **Expansion Factor:** The physical expansion ratio of your biological sample (e.g., 4.0 or 4.5). This value is crucial for accurately calculating the true biological volumes and spatial coordinates. For non-expanded data, simply set this to 1.0.
*   **Probability Threshold:** A threshold value applied to the probability maps to binarize the image. Areas with a probability higher than this value are considered part of a condensate.
*   **Min. size (voxels):** The minimum number of connected pixels (in `2d`/`single_slice` mode) or voxels (in `3d` mode) required to classify a segmented object as a valid condensate. This strictly filters out sub-resolution noise and artifacts. Note that the same numeric value has a different physical meaning depending on the selected mode - a plane's pixel count is not directly comparable to a stack's voxel count, so this may need re-tuning when switching modes.
*   **Process Controls:**
    *   *Show Napari preview:* Toggles the visual rendering of the image data in the main interactive viewer.
    *   *Auto-ROI:* When enabled, treats the entire field of view as a single region of interest, and reported statistics are per field-of-view rather than per cell. If disabled, the software prompts the user to manually draw a specific ROI for each image, enabling per-cell (`cell_id`) statistics.
    *   *Pause and review segmentations:* Halts the batch processing pipeline after each image to allow visual inspection of intermediate segmentation steps before proceeding to the next image.
    *   *Generate Excel stats & Generate plots:* Toggles the automatic creation of descriptive statistics and visual data distributions in your output directory.

### Advanced Settings
Accessible via the top menu bar (`Settings -> Advanced...`), this menu allows to change the core image processing parameters and define your specific hardware and channel configurations.

*   **Gaussian Sigma:** The standard deviation for the Gaussian filter applied to the Ilastik probability map prior to segmentation. Increasing this value smooths the probability map, which helps prevent the over-segmentation (fragmentation) of single, continuous condensates.
*   **Pixel Size XY (nm):** The physical lateral dimension of a single pixel as acquired by your microscope (e.g., 58.0 nm). This is essential for calculating true biological areas and volumes.
*   **Z-step (nm):** The physical axial distance between consecutive slices in your 3D image stack (e.g., 250.0 nm). This is utilized strictly in 3D mode to calculate accurate biological volumes.
*   **Probability Channel:** The array index of the relevant target class in your exported Ilastik `.h5` probability file (default is 0).
*   **Signal Channel:** The channel index in your raw multi-channel `.tif` image that contains the specific condensate signal you wish to quantify (e.g., channel 1 for a target protein).
*   **DAPI Channel:** The channel index in your raw multi-channel `.tif` image corresponding to the nuclear stain (e.g., channel 0).
